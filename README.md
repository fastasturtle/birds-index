# Птицы мира — трёхъязычный указатель

Указатель всех видов птиц мира с названиями на русском, английском и латинском языках, включая недавно вымершие виды (после 1500 года). Систематика — по AviList, только виды, без подвидов. Сайт: https://fastasturtle.github.io/birds-index/

## Источники данных

- AviList v2025b — таксономическая основа (CC BY 4.0).
- IOC World Bird List 15.2 multilingual — русские названия (CC BY 3.0).
- Русские названия: Волков С.В., Коблик Е.А. «Птицы мира: рекомендуемые русские названия видов» (Зоологический музей МГУ).
- eBird/Clements 2025 — запасной источник названий.
- Wikidata — дополнительный источник (CC0).

Подробности — в `data/raw/SOURCES.md`.

## Как пересобрать

```
uv run scripts/build.py
```

Без флагов скрипт скачивает только недостающие файлы. Флаги: `--offline` (без обращения к сети, только уже скачанные файлы в `data/raw/` и `data/cache/`), `--fetch` (заново скачать все источники: xlsx AviList и IOC в `data/raw/`, данные eBird и Wikidata в `data/cache/`). Если eBird или Wikidata недоступны, сборка не падает: используется прежний кэш, а при его отсутствии источник пропускается, что отмечается в `data/report.md`.

Скрипт с нуля генерирует `data/species.json`, `data/report.md` и `docs/data/species.json`.

## Ручные правки

Исправления вносятся в `data/overrides.csv` со столбцами `sci, field, value, note`. Этот слой применяется последним. Сгенерированные файлы вручную не редактируются.

## Данные

Поля записи в `species.json`:

- `id`, `seq` — идентификатор и порядковый номер;
- `order`, `family`, `family_en` — отряд и семейство;
- `sci`, `authority` — научное название и автор описания;
- `en`, `ru` — английское и русское названия;
- `ru_source`, `ru_status` — источник и статус русского названия;
- `ioc_sci` — научное название по IOC (пока не заполняется: сопоставление только по точному совпадению названия);
- `extinct` — признак вымершего вида;
- `iucn` — категория МСОП.
