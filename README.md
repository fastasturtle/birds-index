# Птицы мира — трёхъязычный указатель

Указатель всех видов птиц мира с названиями на русском, английском и латинском языках, включая недавно вымершие виды (после 1500 года). Систематика — по AviList, только виды, без подвидов. Сайт: https://fastasturtle.github.io/birds-index/

## Источники данных

- AviList v2025b — таксономическая основа (CC BY 4.0).
- IOC World Bird List 15.2 multilingual — русские названия (CC BY 3.0).
- Русские названия: Волков С.В., Коблик Е.А. «Птицы мира: рекомендуемые русские названия видов» (Зоологический музей МГУ).
- eBird/Clements 2025 — запасной источник названий.
- Wikidata — дополнительный источник (CC0).

Подробности — в `data/raw/SOURCES.md`.

## Как пересобрать

```
uv run scripts/build.py
```

Без флагов скрипт скачивает только недостающие файлы. Флаги: `--offline` (без обращения к сети, только уже скачанные файлы в `data/raw/` и `data/cache/`), `--fetch` (заново скачать все источники: xlsx AviList и IOC в `data/raw/`, данные eBird и Wikidata в `data/cache/`). Если eBird или Wikidata недоступны, сборка не падает: используется прежний кэш, а при его отсутствии источник пропускается, что отмечается в `data/report.md`.

Названия семейств из списка воробьиных ЗММУ берутся из `data/raw/Birds_rus_names_passerine.xlsx`, названия отрядов и семейств из Wikidata кэшируются в `data/cache/wikidata-taxa-ru.json`.

Сборка также проверяет русские названия (латинские буквы внутри кириллических слов, одно название у нескольких видов, выделенные синонимы, сомнительные ведущие слова) и пишет результаты в `data/report.md`.

Скрипт с нуля генерирует `data/species.json`, `data/taxa.json`, `data/report.md` и их копии `docs/data/species.json`, `docs/data/taxa.json`.

## Печатная версия

Макет книжного издания на [Typst](https://typst.app) лежит в `print/`; данные берутся из `data/species.json` и `data/taxa.json`, всё пересобирается с нуля.

```
uv run --with typst python print/build_print.py                 # выборка: гусеобразные + курообразные, все варианты
uv run --with typst --with pyphen python print/build_print.py --variants C2   # только текущий вариант C2
uv run --with typst --with pyphen python print/build_print.py --variants C2 --full --preview
```

Флаги: `--full` — весь список (11 131 вид) вместо выборки; `--preview` — PNG-превью ключевых полос в `print/out/preview/` (нужен `pdftoppm` из poppler); `--variants` — любые из `A`, `B`, `C`, `C2` подряд (`ABC`, `C2`; по умолчанию все).

- `variant_c2.typ` — текущий вариант «компактный справочник» (итерация 2): 170×240 мм, список в 3 колонки, указатели в 4; выход `print/out/birds_C2_compact.pdf` (выборка) и `birds_C2_compact_full.pdf` (`--full`). Шаблон только верстает: номера, диапазоны, склонение чисел и алфавитные указатели готовит `build_print.py`. Указатели верстаются в два прохода: строки измеряются Typst (`c2_measure.typ` с общим рендерером `c2_index.typ`), затем Python раскладывает их по колонкам и полосам — так получаются строки «гнездо (продолж.)», сбалансированная последняя полоса и колонтитулы «первое — последнее гнездо».
- После колофона идут временные страницы, в издание не входящие: записка «О подготовке этого макета» (текст — `print/about_draft.typ`) и рабочие таблицы (ручные правки, совпадающие названия, запасные названия, виды без названия, синонимы).
- Переносы: в русских названиях автоматических переносов нет; мягкие переносы (pyphen, не меньше трёх букв с каждой стороны, не в дефисных словах) ставятся только в слова, которые не помещаются в строку. Без `--with pyphen` такие слова остаются без переносов (сборка предупредит).
- Проверки после сборки C2 (код выхода 1 при нарушениях): `check_overflow.py` — слова за краем колонки или полосы (`pdftotext -bbox`); `check_layout.py` — автоматические переносы в русских строках, колонки списка, начинающиеся не со статьи или рубрики, год, оторванный от автора, продолжение гнезда указателя из одной строки, прямые апострофы. Вручную: `python print/check_overflow.py <pdf> <layout.json>`, `python print/check_layout.py <pdf> <layout.json> <c2_*.json>` (файлы пишет `build_print.py` в `print/out/`).
- `variant_a.typ`, `variant_b.typ`, `variant_c.typ` и `common.typ` — первые три варианта (итерация 1), оставлены для сравнения.
- Объём по разделам (выборка и факт `--full`) — `print/out/estimate.md`.
- Шрифты — в `print/fonts/` с лицензиями: Gentium Book Plus и PT Serif (SIL OFL 1.1), Source Serif 4 (SIL OFL 1.1, `SourceSerif4-LICENSE.md`).
- В git отслеживаются PDF выборки и `estimate.md`; `*_full.pdf`, промежуточные JSON и `preview/` не отслеживаются (`print/out/.gitignore`).

## Ручные правки

Исправления вносятся в `data/overrides.csv` со столбцами `sci, field, value, note`. Этот слой применяется последним. Сгенерированные файлы вручную не редактируются.

Для видов `field` — любое поле записи, кроме вычисляемых (`ru_source`, `ru_status`, `ru_head_source`, `ru_book`, `en_head`). Особые случаи: `ru_alt` — альтернативные названия через «; », добавляются к выделенным автоматически (без дублей); `ru_head` — ведущее слово вручную (`ru_head_source = "manual"`). Синонимы выделяются из итогового `ru`, то есть и из значения правки `field = ru`.

В `sci` может стоять и латинское название отряда или семейства (как в `order` / `family` записей `species.json`); для них поддерживается только `field` = `ru`, правка попадает в `taxa.json` с `ru_source = "manual"`.

## Данные

Поля записи в `species.json`:

- `id`, `seq` — идентификатор AviList в виде `avibase-` + 8 шестнадцатеричных знаков (например `avibase-240E3390`) и порядковый номер; на сайте он же служит якорем постоянной ссылки (`#avibase-240E3390`), а в ссылку на Avibase подставляется без префикса (`species.jsp?avibaseid=240E3390`);
- `order`, `family`, `family_en` — отряд и семейство;
- `sci`, `authority` — научное название и автор описания в виде AviList (с инициалами, например `Sclater, PL; von Hochstetter, F, 1861`);
- `auth` — автор и год в принятой зоологической форме без инициалов: `Linnaeus, 1758`, `(Latham, 1790)`, `Sclater & von Hochstetter, 1861`, `Tennyson, Palma, Robertson, Worthy & Gill, 2003` (скобки сохраняются; `null`, если `authority` пуст);
- `en`, `ru` — английское и русское названия (`ru` — одно основное название, без синонимов);
- `ru_alt` — список альтернативных русских названий (пустой, если их нет): синонимы, отделённые в источнике запятой, « / », « или » или скобками («Хохлатый фазан, чир» → `ru` «Хохлатый фазан», `ru_alt` ["Чир"]; «Гуменник (лесной гуменник)» → «Гуменник», ["Лесной гуменник"]), плюс правки `field = ru_alt` из `overrides.csv`;
- `ru_head`, `ru_head_source` — ведущее слово («гнездо») русского названия для инвертированного указателя, со строчной буквы: «Белолобый гусь» → «гусь», «Гусь Росса» → «гусь», «Лебедь-шипун» → «лебедь-шипун» (дефисное слово целиком); источник `auto` (эвристика в `build.py`) или `manual` (`overrides.csv`, `field = ru_head`); оба `null`, если нет `ru`;
- `ru_book` — `ru` в «книжной» орфографии: первая буква строчная, кроме притяжательных прилагательных от имён собственных («Стеллерова сойка», «Магелланов гусь»); остальные слова не меняются («гусь Росса»);
- `en_head` — ведущее слово английского названия: последнее слово, дефисное целиком («Scrub-Jay», «Whip-poor-will»);
- `ru_source`, `ru_status` — источник и статус русского названия;
- `ioc_sci` — научное название по IOC (пока не заполняется: сопоставление только по точному совпадению названия);
- `extinct` — признак вымершего вида;
- `iucn` — категория МСОП.

Файл `taxa.json` — отряды и семейства в систематическом порядке (оба массива отсортированы по `seq`):

- `orders[]`: `sci` (латинское название отряда), `ru`, `ru_source`, `seq` (наименьший `seq` вида отряда), `count` (число видов);
- `families[]`: `sci`, `en` (английское название семейства по AviList), `ru`, `ru_source`, `order`, `seq`, `count`.

`ru_source` для отрядов и семейств: `zmmu` (заголовки семейств в списке воробьиных Волкова и Коблика, ЗММУ), `wikidata` (P1843 или русская метка элемента Wikidata), `manual` (`data/overrides.csv`) или `null`, если названия нет.

## Сайт

Статические файлы в `docs/`, без сборщика и фреймворка:

- `docs/index.html` — указатель: систематический список с закреплёнными заголовками отрядов и семейств, поиск, фильтры, постоянные ссылки `#<id>` и состояние поиска в URL;
- `docs/missing.html` — виды без русского названия и виды с названием из запасных источников (eBird, Wikidata, ручной слой), с выгрузкой в CSV;
- `docs/sources.html` — «Источники и ссылки»: данные, версии и лицензии, как цитировать, смежные ресурсы, устройство проекта; статическая, без загрузки данных. Все три страницы связаны строкой навигации в шапке;
- `docs/style.css` — общие стили всех страниц;
- `docs/data/species.json`, `docs/data/taxa.json` — копии данных. Без `taxa.json` страницы работают, но заголовки отрядов и семейств показываются только по-латыни.
