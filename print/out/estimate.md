Экстраполяция линейная: страницы раздела выборки × (элементов в полном списке / элементов в выборке). Для списка — по числу видов; для русского и английского указателей — по числу названий; для латинского — по числу строк (виды + заголовки родов). В варианте A каждый отряд начинается с новой полосы: добавлено ≈0,5 полосы на отряд (в полном списке 46 отрядов).
