Источники и ссылки

Список видов, их порядок, латинские и английские названия взяты из AviList, а русские названия наложены на него по точному латинскому названию: в первую очередь из многоязычного списка IOC, в основе которого лежат рекомендуемые названия С. В. Волкова и Е. А. Коблика (ЗММУ), затем из eBird, Wikidata и ручного слоя правок. Сам указатель показывает источник каждого названия, не взятого из IOC, а отдельная страница перечисляет виды без русского названия и названия из запасных источников.

Как цитировать

Русские названия, таксономию и многоязычный список просим цитировать по первоисточникам:

Волков С. В., Коблик Е. А. Птицы мира: рекомендуемые русские названия видов. Зоологический музей МГУ. zmmu.msu.ru

AviList Core Team. AviList: The Global Avian Checklist, v2025b. doi:10.2173/avilist.v2025b

Gill F., Donsker D., Rasmussen P. (eds). IOC World Bird List (v15.2). doi:10.14344/IOC.ML.15.2

Смежные ресурсы

  • Avibase (Denis Lepage, Birds Canada) — таксономические концепции, синонимы, названия на 100+ языках; наши ссылки на вид ведут туда.
  • Birds of the World (Cornell Lab of Ornithology) — видовые очерки, по подписке.
  • BirdLife DataZone — статус МСОП, ареалы.
  • IUCN Red List — Красный список МСОП.
  • xeno-canto — голоса.
  • Avionary — многоязычный словарь названий голарктических птиц, 63 языка.
  • Коблик Е. А., Архипов В. Ю. «Фауна птиц стран Северной Евразии» (ЗММУ, обновляемая таблица) — актуальные русские названия для Палеарктики.
  • Бёме Р. Л., Флинт В. Е. Пятиязычный словарь названий животных. Птицы. М., 1994 — первый полный русский список птиц мира (печатное издание).
  • Wikispecies — викисправочник по систематике.
